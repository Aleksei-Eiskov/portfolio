# Aleksei Eiskov - QA Engineer Portfolio

Personal QA portfolio focused on API, backend and integration testing, test design and defect analysis.

**[View the portfolio](https://aleksei-eiskov.github.io/portfolio/)**

## What's inside

- **QA examples** - bug reports, test cases, regression coverage and requirements breakdowns, readable directly on the page.
- **QA dashboard** - interactive charts demonstrating coverage, regression duration and defect resolution trends using synthetic data.
- **API project** - a guided walkthrough of the Car_store Postman E2E collection, with seven requests, request bodies and the actual assertion scripts.
- **Experience and skills** - professional background, tools and languages.

## API collections

Both Postman collections are embedded in the page and can be downloaded from the API project section:

- **E2E collection** - create a brand and car, update the car, check relations, then clean up the created records.
- **CRUD collection** - requests for manual exploration of cars, brands, reviews, filters, search, sorting and pagination. This export does not contain implemented assertion scripts.

The portfolio explains the requests and checks. It does not execute API requests or display a recorded test run.

The API service is a separate project: [Car_store](https://github.com/Aleksei-Eiskov/car_store).

## Run locally

Open `index.html` in a browser. No installation or build step is required.

The page content and embedded collections work locally. An internet connection is required for the externally hosted dashboard.
